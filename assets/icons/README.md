# Ícono de NFC Bridge Driver

Coloca aquí `app.ico` (multi-resolución 16x16, 32x32, 48x48, 256x256 RGBA) para el ejecutable y proceso/servicio de **NFC Bridge Driver** en Windows.
Si `app.ico` no existe, `build.rs` incrusta automáticamente un respaldo procedural y `VERSIONINFO` (`FileDescription = "NFC Bridge Driver"`) para que el Administrador de tareas no lo muestre como `.exe`.
